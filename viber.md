# Viber API quickstart

This example demonstrates how to use the [Infobip Viber API](https://www.infobip.com/docs/api/channels/viber). You'll learn how to initialize a Viber client,
send a message, manage templates, and receive a delivery report.

Initialize Send Viber API client:

```java
    ApiClient apiClient = ApiClient.forApiKey(ApiKey.from(API_KEY))
        .withBaseUrl(BaseUrl.from(BASE_URL))
        .build();

    ViberApi viberApi = new ViberApi(apiClient);
```

Before sending a Viber message, you need to have your Viber sender registered and activated with Infobip.

## Send a Viber message

The `messages[].sender`, `messages[].destinations[].to`, and `messages[].content` fields are required.

---
**IMPORTANT NOTE**

Keep in mind the following restrictions while using a trial account:

- you can only send messages to numbers verified on your account.

---

```java
    ViberRequest viberRequest = new ViberRequest()
        .addMessagesItem(new ViberMessage()
            .sender("ExampleSender")
            .addDestinationsItem(new ViberToDestination()
                .to("41793026727"))
            .content(new ViberOutboundTextContent()
                .text("Hello from Infobip Viber!")));

    MessageResponse response = viberApi
        .sendViberMessages(viberRequest)
        .execute();
```

## Manage Viber templates

Template management lives under `/viber/1/senders/{sender}/templates`. All template endpoints are currently marked `@Beta`. Templates must be approved by Viber before they can be used for sending messages.

### Create a template

The `category` and `body` fields are required. Each template body carries a `language` and a `template` string; `body` is currently limited to one entry per template. For the `OTP` category, at least one parameter with name `{{pin}}` is required.

```java
    String sender = "ExampleSender";

    ViberTemplateRequest templateRequest = new ViberTemplateRequest()
        .category(ViberTemplateCategory.TRANSACTIONAL)
        .addParamsItem(new ViberTemplateParam()
            .name("firstName")
            .type(ViberTemplateParamType.TEXT)
            .example("John"))
        .addBodyItem(new ViberTemplateBody()
            .language(ViberTemplateLang.EN)
            .template("Hello {{firstName}}, your order has been confirmed."));

    ViberTemplateResponse created = viberApi
        .createViberTemplate(sender, templateRequest)
        .execute();

    String templateId = created.getTemplateId();
    ViberTemplateStatus status = created.getStatus();
```

### List, fetch, and delete templates

```java
    ViberTemplatesResponse templates = viberApi
        .getViberTemplates(sender)
        .execute();

    ViberTemplateResponse template = viberApi
        .getViberTemplate(sender, templateId)
        .execute();

    viberApi.deleteViberTemplate(sender, templateId).execute();
```

Deleted templates can no longer be used for sending messages.

## Send a template message

Once your template is approved, send it with `ViberOutboundTransactionalTemplateContent`. The `templateId` and `language` fields are required; `language` must match the `lang` parameter from template creation (the `String` form of `ViberTemplateLang`, e.g. `"en"`). Omit `parameters` if the template has none.

```java
    ViberOutboundTransactionalTemplateContent content = new ViberOutboundTransactionalTemplateContent()
        .templateId(templateId)
        .language(ViberTemplateLang.EN.getValue())
        .putParametersItem("firstName", "John");

    ViberRequest viberRequest = new ViberRequest()
        .addMessagesItem(new ViberMessage()
            .sender(sender)
            .addDestinationsItem(new ViberToDestination()
                .to("41793026727"))
            .content(content));

    MessageResponse response = viberApi
        .sendViberMessages(viberRequest)
        .execute();
```

## Delivery reports

For each message that you send out, we can send you a delivery report in real time.
All you need to do is specify your endpoint when sending a Viber message in the message's `webhooks.delivery.url` field.
You can use data models from the library and the pre-configured `com.infobip.JSON` serializer.

Additionally, you can use a `messageId` or a `bulkId` autogenerated in a response for troubleshooting and to fetch reports.

```java
    String bulkId = "BULK-ID-123-xyz";
    Integer numberOfReportsLimit = 10;

    ViberWebhookReportsResponse deliveryReports = viberApi
        .getOutboundViberMessageDeliveryReports()
        .bulkId(bulkId)
        .limit(numberOfReportsLimit)
        .execute();
```
